One out-of-office reply, one line, written to make a colleague laugh instead of sighing at an inbox notice. It hands the urgent stuff to a houseplant with firm boundaries and no Wi-Fi — a fresh turn on the usual away message, funny on the first read, and still something a real person would switch on before going away.

> I'm away — please direct all urgent matters to my houseplant. It has firm boundaries and no Wi-Fi.

The line is 98 characters, one line, no signature or name needed — inside the
bounty's gate of 1 to 160 characters of UTF-8 text in `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program prints the reply and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
